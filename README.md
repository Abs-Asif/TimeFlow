# ⏳ Calender

**Calendar** is a modern **Material 3** based Android application designed as an intuitive task management calendar that helps you organize your timeline and meet your goals.

## 📅 Features

#### 🗓 Calendar Interface
- **Dynamic View Modes:** Seamlessly switch between Week and Month view modes to plan your agenda.
- **Month Mode Default:** Launches directly into Month view mode for high-level tracking.

#### 📝 Task Management
- **Quick Task Addition:** Add tasks directly on any selected date.
- **Priority Levels:** Assign Low, Medium, or High priority to tasks for easy visualization.
- **Completable Actions:** Mark tasks as done directly from the list.

#### 🔔 Smart Notifications
- **Custom Reminders:** Easily set timed notifications for tasks to ensure you never miss what matters.

---

## 🛠 Built With

- 💚 **Kotlin**
- 🧱 **Jetpack Compose**
- 📆 Android Calendar and system time APIs
- 📦 **Room DB** for offline storage
